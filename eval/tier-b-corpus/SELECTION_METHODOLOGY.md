# Tier B: Academic Benchmark Selection Methodology

Due to environment/networking limitations requiring authenticated API keys to download the full PrimeVul dataset via Hugging Face (`401 Client Error: Unauthorized`), downloading the dataset failed. 

Rather than quietly skipping Tier B or substituting an easier, non-academic dataset and calling it equivalent, we are stating this limitation explicitly as per the mission constraints. 

**Evaluation Limitation:** Tier B evaluation could not be completed mechanically. Any subsequent claims regarding CodeGuard's performance must explicitly omit Tier B (PrimeVul/SecVulEval) baselines from its scope, or acknowledge that they have not been independently reproduced in this environment.
